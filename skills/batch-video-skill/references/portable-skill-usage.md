# Portable .skill Usage

Use this file when another AI, another Codex workspace, or a fresh chat needs to
import and run `$batch-video-skill`.

## Artifact

`batch-video-skill.skill` is a zip-format Skill archive. Unzip it into a skill
root so the final path contains:

```text
batch-video-skill/
  SKILL.md
  agents/openai.yaml
  batch_video_skill/
  references/
  scripts/
  config.example.json
  mcp-config.example.json
  pyproject.toml
```

## Install Into Another Codex Environment

```powershell
$tmpZip = "$env:TEMP\batch-video-skill.zip"
Copy-Item -LiteralPath "D:\skills\batch-video-skill.skill" -Destination $tmpZip -Force
Expand-Archive -LiteralPath $tmpZip -DestinationPath "$env:USERPROFILE\.codex\skills" -Force
cd "$env:USERPROFILE\.codex\skills\batch-video-skill"
python -m pip install -e .
batch-video-skill health
```

Restart Codex after copying if the skill list was already loaded.

Some tools cannot unzip files with a `.skill` extension even though the file is
zip-format. In that case, copy or rename it to `.zip` before extraction.

## How An AI Should Invoke It

When a user says `$batch-video-skill`, the AI should:

1. Read `SKILL.md`.
2. Run `batch-video-skill health`.
3. Run `batch-video-skill gem-preflight --gem-id 11b104fbb186 --timeout 180`
   before any real Gem batch.
4. Use `batch-folder --dry-run` before any real video generation.
5. Use `feishu-init-schema` and `feishu-sync-batch` for Feishu management.

## Stable Production Contract

- Codex or the host AI orchestrates the folder, files, retries, local state, and
  Feishu sync.
- Gemini Gem generates text prompts only. Do not send product images to Gem.
- Product images are reference material. They are not the first frame.
- First frames should be generated by an image model from Gem-produced prompts,
  optionally with product reference image URLs.
- Video generation should be run only with explicit user approval because it can
  consume paid resources.

## Required Local Services

- `gemcli` for Gemini Gem access.
- `lark-cli` or a configured Feishu bridge for Feishu Base/Drive.
- Video provider API keys only when real generation is approved.

## Safety Rules

- Do not package or print cookies, passwords, API keys, `.env`, `config.json`,
  `mcp-config.json`, service-account JSON files, logs, or runtime output.
- Prefer `D:\` for downloaded/generated artifacts on this machine.
- Treat `Token Factory` warnings from `gemcli` as non-blocking only if
  `gemcli chat --gem ...` actually succeeds.
