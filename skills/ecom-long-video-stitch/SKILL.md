# 带货长视频无缝拼接

把"单段 10-15 秒"的 AI 视频拼成 1-2 分钟长视频时，拼接感只来自四个地方。堵住这四个来源，接缝就消失了：

| 拼接感来源 | 表现 | 对策层 |
|---|---|---|
| ① 跳切 | 相邻两段景别机位太近，画面"跳了一下" | 设计层：景别阶梯 + 转场手法 |
| ② 视觉跳变 | 人脸/服装/产品/光线/色调突变 | 生成层：一致性锁 + 续帧 |
| ③ 动作断裂 | 上一段动作没做完，下一段另起炉灶 | 设计层：动作重叠 + 匹配剪辑 |
| ④ 音频断裂 | BGM/口播/环境音在接缝处断开或音量跳 | 后期层：整轨 BGM + J/L-cut |

对应三层防线：**设计层**（剪辑点设计，本文件 + `references/transitions.md`）、**生成层**（一致性控制，`references/continuity.md`）、**后期层**（FFmpeg 实操，`references/ffmpeg.md` + `scripts/stitch.py`）。

按用户所处阶段路由，不要一次读完所有 reference：

| 用户需求 | 做什么 |
|---|---|
| 从产品/脚本开始规划长视频 | 走下面 Phase 1-4，读 `references/transitions.md` |
| 已有分段脚本，要设计接缝和提示词 | Phase 2-4，读 `references/transitions.md` + `references/continuity.md` |
| 段与段之间人物/产品变脸、漂移 | 读 `references/continuity.md` |
| 视频已生成，要拼接/加转场/铺BGM | 读 `references/ffmpeg.md`，用 `scripts/stitch.py` |
| 拼完发现接缝明显，要诊断 | 本文件"验收与重跑" + `references/ffmpeg.md` 的 QC 部分 |

默认按 Seedance 2.0/即梦的特性写提示词（支持首帧图参考、图生视频、10/15 秒档位）；用户用其他模型时保持同样结构，标注需替换的参数。默认中文沟通，视频内提示词用英文。

## Phase 1：分段规划

先问清（或从上下文提取）：目标总时长、画面比例、单段上限（默认 10s，可 12/15）、内容形式（口播/剧情/测评/混合）、产品与卖点、是否有固定人设图。

**留余量规划**：模型经常吃秒、结尾冻结。按"名义段长 - 1.5 秒"规划内容量（例：设计 15 秒的段，内容只排 13 秒），宁短勿拖。

**段数 = ceil(总时长 ÷ (单段上限 - 1.5))**，然后把带货节奏骨架铺到段上：

| 60 秒示例（6 段 × 10s） | 内容职责 |
|---|---|
| 段1 0-10s | 钩子 + 痛点场景 |
| 段2 10-20s | 产品登场 + 第一卖点 |
| 段3 20-30s | 核心卖点演示（效果可视化） |
| 段4 30-40s | 第二卖点 / 对比实测 |
| 段5 40-50s | 信任建立（细节/证言/场景蒙太奇） |
| 段6 50-60s | 促销 + CTA |

90/120 秒按同比例扩展中间的"演示/信任"部分，钩子和 CTA 不变长。**每个拼接点尽量安排在内容职责的切换处**——内容本来就该换镜头的地方，剪辑最不显眼。

## Phase 2：拼接点设计（核心）

给每个拼接点（N 段有 N-1 个）**指定一种电影转场手法**，写进规划表。手法库、每种手法 A 段末/B 段首的具体写法、适用场景见 `references/transitions.md`。速记：

- **兜底规则（任何拼接点必须满足）**：景别阶梯——相邻两段接缝处必须跨 2 级景别（如全景→特写），且机位方向变化超过 30 度。做不到就是跳切。
- **首选手法（带货最实用）**：特写桥（产品/手部特写做桥梁，特写无背景信息、跨段误差最小）、动作匹配剪辑（动作跨越剪辑点）、遮挡切（手/物扫过镜头）。
- **动作匹配必须"重叠拍两遍"**：A 段末尾生成完整动作的前 2/3，B 段开头生成同一动作的后 2/3，两段重叠约 1 秒，后期在动作中点切、各丢一半。不要指望两段严丝合缝对上——重叠才有剪辑余地。
- 同一条视频里转场手法至少用 3 种轮换，全片只用一种也会形成"套路感"。

## Phase 3：逐段输出

每一段按此模板输出（这是本 skill 的标准交付格式）：

```
【段 N/总数】职责：<节奏骨架职责>　时长：设计 Xs / 生成档位 Ys
拼接点手法（与上一段）：<手法名，段1写"无">
首镜头（承接设计）：<如何回应上一段的段末状态>
内容分镜：<2-4 个镜头的中文描述>
段末状态卡：
  - 人物：姿态/视线方向/表情
  - 产品：在画面中的位置/被谁拿着/朝向
  - 镜头：景别/机位方向/是否在运动中
  - 光线：光源方向/色温/时间感
  - 动作：正在进行的动作进行到哪一步（供下一段承接）
Seedance/即梦英文提示词：<含一致性锁前缀+本段内容+通用后缀>
口播（如有）：<跨段句设计见 transitions.md 的 J/L-cut 条目>
```

提示词必须包含一致性锁（人物 DNA 串、产品锁定串、场景锚点、光线锁），写法见 `references/continuity.md`。续帧法（抽上一段末帧作为下一段首帧参考图）什么时候用、什么时候不用，也在那个文件里。

## Phase 4：生成后验收与重跑

拿到各段成片后，逐个拼接点检查五项：人脸一致 / 服装发型一致 / 产品外观一致 / 光线色调连续 / 动作可衔接。发现问题时的重跑策略：

- 只重跑崩掉的那一段，不要全部重来；
- 人脸漂移：改用续帧法或首帧图重跑该段；
- 光色跳变：优先后期统一（LUT/色彩匹配，见 ffmpeg.md），不值得为色温重跑；
- 动作对不上：检查是否有重叠余量，没有就把 B 段首镜头改为特写桥再重跑 B 段（特写容错最高）。

## Phase 5：FFmpeg 拼接

读 `references/ffmpeg.md`。顺序固定：**先统一参数转码 → 再拼接 → 再处理音频 → 最后 QC**。参数不一致（分辨率/帧率/像素格式）本身就是一种"拼接感"。

快捷方式：`scripts/stitch.py` 一条命令完成探测、统一转码、硬切或微溶解拼接、BGM 铺底：

```bash
python scripts/stitch.py <clips目录或文件列表> -o final.mp4 --transition dissolve --dissolve 0.15 --bgm bgm.mp3
```

拼完必须做接缝 QC：抽取每个拼接点前后 0.2 秒的帧拼图对比（命令见 ffmpeg.md），确认无跳变再交付。

## 交付时的完整输出结构

规划类任务按此结构交付：① 分段规划表（段数/职责/时长/拼接手法）→ ② 逐段模板输出 → ③ 一致性锁汇总（人物 DNA、产品锁，方便复制）→ ④ 生成注意事项 → ⑤ 拼接阶段的 FFmpeg 指引。拼接类任务直接给可执行命令 + QC 步骤。
